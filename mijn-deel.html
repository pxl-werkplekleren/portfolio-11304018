Mijn Deel

Graduaat Programmeren

Mijn bijdrage aan het project

Als student van Graduaat Programmeren stond ik voor ons project vooral in voor het helpen functioneel maken van onze back-end. Daarnaast heb ik meegeholpen met het opstellen van ons ERD-schema en dit functioneel te maken binnen onze SQL-database.

Ook heb ik een van de tools die wij gebruiken voor het managen van ons project in het begin op orde gezet, met name Jira.

Sprint 1

Het ERD-schema opstellen en het aanmaken van onze databases waren enkele van de eerste taken die ik had tijdens Sprint 1.

Daarnaast heb ik toen ook een tijdje gespendeerd aan het opschonen van onze Jira-pagina, aangezien deze in het begin redelijk overhoop was gehaald. Dit deed ik zowel voor ons als PRO-studenten, maar ook voor de studenten van DVO-Web en DVO-Design.

Ook heb ik hier en daar meegeholpen met kleine stukjes programmeren van de back-end.

Sprint 2

In Sprint 2 ben ik vooral bezig geweest met het programmeren in de back-end.

Ik heb een groot aantal van onze back-end services, controllers, database-implementaties en functionaliteiten op onze Swagger back-end pagina verzorgd.

Dit was in het begin even zoeken om volledig te begrijpen hoe alles functioneerde. Nadat ik dit voor een paar tabellen van onze database had aangemaakt, ging de rest een stuk vlotter.

Ook ben ik hier en daar enkele bugs tegengekomen tijdens het testen van deze functionaliteiten. Hierdoor heb ik mij ook kunnen bezighouden met debuggen en het oplossen van deze bugs, zodat alles uiteindelijk volledig functioneel was.

Sprint 3

Als laatste had ik in Sprint 3 de taak om onze e-mailservice te implementeren.

Dit was voor mij persoonlijk een zeer moeilijke taak, aangezien veel van de informatie die ik online vond meestal verouderd was en ik daardoor vaker op het foute spoor zat.

Na een tijdje heb ik het wel volledig functioneel gekregen in onze back-end. Hierna moest ook nog de implementatie naar de front-end website gebeuren, dus deze taak heb ik verder uitgevoerd.

Aangezien ik op dat moment niet veel ervaring had met onze front-end en mij vooral op de back-end had gefocust, was het veel onderzoeken en kijken hoe onze bestaande front-end pagina werkte.

Ook moest ik goed opletten dat ik naast het implementeren van deze e-mailservice de bestaande delen niet kapot maakte.

Reflectie op mijn bijdrage

Uiteindelijk vind ik dat ik een mooie bijdrage heb geleverd aan dit project, ondanks mijn matige kennis in vergelijking met sommige anderen in ons team die al enkele jaren programmeerervaring hadden.

Ik ben dan ook trots op mijn eigen geleverde functionaliteiten en andere opdrachten die ik heb uitgevoerd voor ons project.

Ook ben ik zeer trots op het geleverde eindresultaat van ons project.
